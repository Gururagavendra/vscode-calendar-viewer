# Outlook Calendar & Email Viewer

> View your Microsoft Outlook calendar events and emails directly in VS Code

## ✨ Features

**Stay on top of your schedule and inbox without leaving your editor**

- 🔐 Secure sign-in with your Microsoft account
- 📅 View upcoming events for the next 7 days
- 📧 Browse your inbox with unread/read grouping
- 🎨 Clean sidebar interface with organized views
- 🔄 One-click refresh to sync latest data
- 🌐 Click any event or email to open in browser
- 💼 Works with personal, work, and school accounts

## 🚀 Quick Start

1. Click the **Outlook Calendar** icon in the Activity Bar (left sidebar)
2. Click **Sign In with Microsoft**
3. Authorize in your browser
4. Done! Your events and emails appear automatically

## 📸 How It Works

Once signed in, you'll see:

### Calendar View
- Events organized by date
- Event time and location
- Upcoming meetings for the next week
- Refresh button to sync anytime

### Email View
- Recent inbox messages
- Grouped by unread/read status
- Email preview and sender info
- Filter to show unread only
- Attachment indicators
- **Read emails directly in VS Code** (no browser needed!)
- Quick actions: Open in Outlook, Reply, Forward

Click any email to read it in a VS Code panel, or right-click for more options.

## 🔒 Privacy & Security

- OAuth 2.0 secure authentication (no passwords stored)
- Only reads your calendar and emails (no modification access)
- Your data stays private - nothing is shared
- Tokens managed securely by VS Code
