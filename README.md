# Outlook Calendar Viewer

> View your Microsoft Outlook calendar events directly in VS Code

## ✨ Features

**Stay on top of your schedule without leaving your editor**

- 🔐 Secure sign-in with your Microsoft account
- 📅 View upcoming events for the next 7 days
- 🎨 Clean sidebar interface with events grouped by date
- 🔄 One-click refresh to sync latest events
- 🌐 Click any event to open in browser
- 💼 Works with personal, work, and school accounts

## 🚀 Quick Start

1. Click the **Outlook Calendar** icon in the Activity Bar (left sidebar)
2. Click **Sign In with Microsoft**
3. Authorize in your browser
4. Done! Your events appear automatically

## 📸 How It Works

Once signed in, you'll see:
- Events organized by date
- Event time and location
- Upcoming meetings for the next week
- Refresh button to sync anytime

Click any event to open it in Outlook web.

## 🔒 Privacy & Security

- OAuth 2.0 secure authentication (no passwords stored)
- Only reads your calendar (no modification access)
- Your data stays private - nothing is shared
- Tokens managed securely by VS Code
